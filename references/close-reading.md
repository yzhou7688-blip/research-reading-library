# 四部分精读

每篇先忠实重建原文，再分析其价值。正文按用户问题展开，表格用于问题—方法—结果对应。原始研究、综述、理论论文、观点文章采用相应的问题、证据与论证结构；不为没有实证设计的文章填造数据与实验。

## 一、研究背景与问题形成

说明已有研究做了什么、关注什么、作者提出何种具体不足、本文补充什么。重建“现象/争议—已有解释—具体缺口—本研究目标”。作者提出的缺口与阅读者对其成立程度的判断分别表述。

复杂概念按“定义—本文含义—简短例子”解释。例子标为解释性示例，不当作本文数据。解释深度以用户理解研究逻辑所需为准。

## 二、研究问题、数据与方法

逐项填写：研究问题/假设、所需数据与变量、方法、选择理由与依据、如何回答问题、原文位置。

说明数据来源和获取条件、总体与样本、研究单位、时空尺度、变量操作化、方法输入/步骤/输出、基准或反事实、识别条件和验证方式。方法解释要说明从什么信息得到什么答案。

作者明确说明的方法选择理由附定位；根据设计分析出的理由标为“阅读分析”。作者未说明的理由不写成作者原意。数据集、方法及结论的适用条件随相关内容表达。

## 三、结论、贡献与后续问题

逐项回应研究问题，记录主要发现、关键数值、图表和论证位置。说明理论、经验、数据或方法贡献。描述、关联、预测和因果结论按原设计表达。

分清作者自述局限、阅读分析发现的问题、作者建议的未来方向及本次阅读延伸问题。评价指出具体问题影响了哪个结论；相反或不利结果按其实际意义记录。补充材料或代码核查根据当前问题开展，记录实际检查范围。

## 四、与当前研究的关联

研究判断表：文献的具体发现/论述 → 可支撑或修正的判断 → 用于当前研究的位置 → 适用条件 → 原文位置。

方法用途表：拟解决任务 → 方法及可借鉴环节 → 所需数据 → 需要调整或验证的条件 → 原文位置。

关系可为支持、限定、相反发现、概念依据或启发。启发与待检验推论明确标注；不把概念依据视为独立实证支持。记录“促使我们重新考虑什么”和后续引文线索。没有直接关联时照实说明。

## 阅读位置与状态

关键发现、方法及可引用论述定位到PDF物理页码；若使用印刷页码同时注明。图表号、章节、补充材料文件与页码分别记录。不能定位时明确缺项，不补造页码。

卡片元数据`reading_stage`使用unread/abstract/partial/full_text；在阅读范围栏说明正文、方法、补充材料和代码实际覆盖。全文阅读与方法复现分别记录。用户笔记独立保存。完成后同步目录的AI阅读状态，用户阅读状态以其确认更新。
